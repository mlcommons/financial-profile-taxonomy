# Inter-agent Layer

## Layer Overview

**Axis:** Control envelope (C)

**Layer:** Inter-agent

**Applies to:** Multi-agent systems only

**ID pattern:** `CE.AGENT.n`

**Scope of the layer:** Trust boundaries between agents, message validation, delegation permissions, credential isolation, and cascade limits with caps on the scope of propagated failure.

## Scope

Applies to **multi-agent systems only**: systems in which agents communicate (e.g., via MCP or A2A protocols), delegate tasks, or pass credentials. The Profile also records what a second agent may do on behalf of the agent being profiled, and the composite domain includes the inter-agent channel.

## Documentation Status

Control names and IDs are fixed in v0.1.0. For each control, the following are open contributions (see [CONTRIBUTING.md](../../../CONTRIBUTING.md#4-control-submission)):

- **Definition**: what the control does and what it does not do
- **Configuration parameters**: what a Profile must record about how it is configured
- **Evidence by assurance level**: what supports a Level 1 assertion vs. a Level 2/3 test
- **Crosswalk**: corresponding OWASP, NIST, and sector-catalogue controls
